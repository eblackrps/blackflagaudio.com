Workflows

Built around review, not surprise.

Library scanning

Add folders, rescan roots, track missing files, and browse albums, artists, and tracks from a SQLite library database.

  • MP3, FLAC, WAV, M4A, AAC, OGG, Opus, AIFF
  • Search by title, artist, album, file name, or path
  • No scan-time file edits

Duplicate review

Compare exact and likely duplicate groups, pick a keeper, save notes, and generate a cleanup plan only after review.

  • SHA-256 checks for exact duplicates
  • Quarantine-only cleanup execution
  • Restore support from app data

Metadata and artwork

Preview metadata suggestions, inspect cover-art candidates, and create dry-run plans before any supported metadata write.

  • Verified MP3 and FLAC field writes
  • Backups before writes
  • Artwork lookup/cache without embedding

Safety boundaries

The beta is intentionally conservative.

BlackFlag is not a bulk organizer, tag sweeper, or automatic cleanup bot. The current build keeps risky actions behind previews, verification, backups, and typed confirmation.

No permanent delete
Cleanup moves eligible files to quarantine under app data.
No automatic online lookup
MusicBrainz and Cover Art Archive are contacted only after a click.
No artwork embedding
Cover art can be cached and planned; embedding is blocked.
No broad file organization
The app does not rename, sort, or restructure a music folder.
