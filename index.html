Beta boundaries

Conservative by design.

The current beta favors traceable previews, typed confirmations, app-data backups, and restore paths over invisible automation.

No permanent delete
Duplicate cleanup moves eligible files to app-data quarantine.
No automatic provider polling
Online cover-art lookup happens only after a user action.
No artwork embedding
Artwork can be cached and planned, but embedding remains blocked.
Backed-up metadata writes
Supported MP3 and FLAC fields require verification and typed confirmation.
