# BlackFlag Audio Website

This repository contains the public website for [BlackFlag Audio](https://blackflagaudio.com/).

BlackFlag Audio is a local Windows music player and library manager. The current product line is in private beta and is built around four jobs:

- **Play** local music from your own library.
- **Scan** folders without rewriting them.
- **Clean** duplicate files through review and quarantine rather than permanent automatic deletion.
- **Fix** tags and artwork with preview-first changes.

## Product Rule

BlackFlag does not freestyle on your library.

No permanent duplicate deletion, surprise metadata writes, automatic provider calls, or silent folder rearrangement.

## Repository Scope

This repo is the static GitHub Pages site only. It contains the public product page, styling, site assets, and custom-domain configuration.

```text
index.html
styles.css
assets/
CNAME
```

The BlackFlag Audio application source is not published in this repository.
